# KOOMPI Linux

An original Linux core that molds into any target — cloud, desktop, phone, automotive, AI appliance.
Its own userland, built from source, downstream of no existing distribution.

Start with [intent.md](intent.md), then [spec.md](spec.md) and [plan.md](plan.md).
[docs/DESIGN.md](docs/DESIGN.md) is the running system as designed for this era, downstream of the spec.
The three attempts that came before are in [docs/POSTMORTEM.md](docs/POSTMORTEM.md), which is the only thing carried across from them.

Built with an agent-native SDLC: intent → spec → plan → diff → review, each stage a committed artifact.
